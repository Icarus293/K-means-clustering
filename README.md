# 📊 PHÂN KHÚC KHÁCH HÀNG TRUNG TÂM MUA SẮM SỬ DỤNG THUẬT TOÁN K-MEANS  
###  Ứng dụng Machine Learning trong phân tích hành vi tiêu dùng  

##  Mục tiêu dự án  
Dự án này áp dụng phương pháp **phân cụm K-Means** để phân loại khách hàng dựa trên dữ liệu thẻ thành viên, bao gồm:  

- **Mã khách hàng**  
-  **Độ tuổi & Giới tính**  
-  **Thu nhập hàng năm**  
-  **Điểm chi tiêu**  

Thông qua phân tích hành vi mua sắm, dự án hướng đến việc xây dựng mô hình phân khúc khách hàng, hỗ trợ các chiến lược tiếp thị cá nhân hóa, cải thiện trải nghiệm người dùng và tối ưu hóa doanh thu.  

---

##  Phương pháp và công nghệ  
- **Xử lý dữ liệu**: Pandas, NumPy  
- **Trực quan hóa dữ liệu**: Matplotlib, Seaborn  
- **Mô hình phân cụm**: Scikit-learn (K-Means)  
- **Môi trường lập trình**: Python
